# 🧬 Portal de Biologia

Uma plataforma web moderna e interativa desenvolvida para facilitar o ensino e a gestão de conteúdos de biologia. O sistema permite o gerenciamento eficiente de materiais didáticos e mantém um catálogo organizado de informações sobre diferentes espécies, otimizando o acesso ao conteúdo.

## ✨ Recursos Principais

* **Gestão de Materiais Didáticos:** Upload e organização centralizada de slides, listas e apostilas.
* **Visualizador de PDF Integrado:** Leitura e navegação pelos materiais de aula diretamente na plataforma, sem a necessidade de downloads externos.
* **Catálogo de Espécies:** Banco de dados interativo para cadastro, consulta e detalhamento de informações biológicas.
* **Armazenamento em Nuvem:** Gestão segura e otimizada dos arquivos de mídia e documentos.
* **Interface Dinâmica e Animada:** Navegação fluida com feedback visual responsivo em todos os dispositivos.
* **Autenticação Segura:** Proteção de rotas e controle de acesso integrado.

## 💻 Tecnologias Utilizadas

Este projeto foi construído utilizando um ecossistema moderno para garantir alta performance e escalabilidade:

* **[Next.js 16](https://nextjs.org/)** - Framework React para renderização otimizada e construção de rotas.
* **[React 19](https://react.dev/)** - Biblioteca principal para construção da interface de usuário.
* **[Tailwind CSS v4](https://tailwindcss.com/)** - Framework para estilização rápida e responsiva.
* **[Mongoose](https://mongoosejs.com/)** - Modelagem elegante de objetos para o banco de dados MongoDB.
* **[@vercel/blob](https://vercel.com/docs/storage/vercel-blob)** - Solução em nuvem para upload e armazenamento de arquivos e imagens.
* **[React-PDF](https://github.com/wojtekmaj/react-pdf)** - Componente robusto para a exibição dos PDFs no navegador.
* **[Framer Motion](https://www.framer.com/motion/)** - Biblioteca poderosa para criação de animações e transições na interface.
* **[Jose](https://github.com/panva/jose)** - Tratamento e validação de tokens JWT para o sistema de autenticação.
* **[Lucide React](https://lucide.dev/)** - Coleção de ícones vetoriais bonitos e consistentes.
